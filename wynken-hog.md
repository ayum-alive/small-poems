# Hedgehog lullaby (after Eugene Field)

Wynken, Blynken and Nod set sail
in a wooden shoe, for stars.
Hedgehog, Prickle and Snore set out
in a teacup, on puddles, for jars.

The old moon asked, "And what do you fish?"
"Beetles," said Snore. "Just two."
The moon laughed so hard the whole sky shook
and a little rain fell through.
